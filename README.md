# Task-12-Power-BI-Data-Transformation-using-Power-Query
**Project Description**

This project focuses on cleaning, transforming, and preparing an HR Analytics dataset using Power Query in Power BI.
The objective of this task is to convert raw HR data into a clean and structured format and then create meaningful visualizations for analysis.

**Tools Used**

Power BI Desktop

Power Query Editor

**Dataset Information**

_HR Analytics Dataset_

The dataset contains employee-related details such as:

1.Age, Gender, Marital Status

2.Department and Job Role

3.Monthly Income and Job Level

4.Work Life Balance

5.Attrition status

**Data Transformation Process**

The following steps were performed using Power Query:

1.Imported the HR dataset into Power BI

2.Removed unnecessary columns such as EmployeeCount, Over18, and StandardHours

3.Renamed columns to improve readability

4.Checked and handled missing or null values

5.Corrected data types for numeric and text fields

6.Created conditional columns:

    .**Age Group **(Young, Adult, Senior)

    .**Salary Band **(Low, Medium, High)

7.Applied changes and loaded the cleaned data into the Power BI model

**Visualizations Created**

The following visualizations were built using the transformed data:

1.Attrition by Department

2.Attrition by Job Role

3.Employees by Age Group

4.Gender Distribution

5.Salary Band vs Attrition

6.Monthly Income by Job Level

7.Work Life Balance vs Attrition

8.Years at Company vs Attrition

**KPI Cards**

1.Total Employees

2.Total Attrition Count

3.Average Monthly Income

**Deliverables**

1.task12_transform.pbix – Power BI project file

2.dashboard_export.pdf – Exported dashboard

3.transformation_notes.txt – Summary of data cleaning steps

**Key Learnings**

1.Practical use of Power Query for data cleaning

2.Importance of correct data types in analysis

3.Creating conditional columns for better insights

4.Building effective HR dashboards in Power BI

**Conclusion**

This task helped me gain hands-on experience in transforming real-world HR data using Power BI.
It improved my understanding of data preparation, transformation, and visualization, which are essential skills for a Data Analyst role.
